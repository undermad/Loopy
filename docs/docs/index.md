# Loopy

Loopy is a desktop tool for game design and project management. It runs fully offline on Windows, macOS and Linux. The product scope will be written here as features land; today the repository holds a complete, tested Electron scaffold.

## How this documentation is organised

| Page                                | Read it when                                            |
| ----------------------------------- | ------------------------------------------------------- |
| [Getting started](getting-started)  | you want to run the app on your machine                 |
| [Architecture](architecture)        | you need to know where code goes and how processes talk |
| [Development workflow](development) | you are about to commit or open a pull request          |
| [Testing](testing)                  | you are adding or running tests                         |
| [Styling](styling)                  | you are writing SCSS or adding a component              |
| [Tooling](tooling)                  | you wonder why a tool is in the repository              |
| [Decisions](./decisions/index.md)   | you want to know why something was chosen               |
| [Roadmap](roadmap)                  | you want to know which features are being considered    |

Every page is updated in the same commit as the change it describes.
