# 0002 npm as package manager

## Context

pnpm offers stricter resolution and faster installs. npm is already installed and understood by every contributor and every CI image.

## Decision

npm 11 with a committed lockfile for the root and for `docs/`.

## Consequences

Slightly slower CI installs. Switching to pnpm later is a lockfile change and a Dependabot setting.
