# 0018 i18next for translations

## Context

Every visible string must be translatable from the start, with English first and more languages later, and the main process needs the same strings for dialogs.

## Decision

`i18next` with `react-i18next` in the renderer and plain `i18next` wherever main needs text. Resources are JSON files per language and namespace under `src/shared/locales`, bundled through `src/shared/i18n.ts`, with keys typed through `CustomTypeOptions`.

## Consequences

Components depend on `useTranslation` from `@renderer/lib/i18n` only, so the library can be swapped behind that entry point. Runtime resources keep the door open to language packs loaded from disk. Compile-time alternatives such as Lingui were not chosen for that reason.
